Use case: ui-mockup
Asset type: high-fidelity desktop web application composition for Eigen, a developer-facing payment-agent evaluation dashboard
Primary request: Design a premium, production-realistic local dashboard called Eigen in a FINANCIAL FLIGHT RECORDER visual world. This is Composition A: axial evidence track. The visitor must understand in seconds that one authorised refund happened exactly once despite a lost response.
Scene/backdrop: full 16:10 desktop browser viewport, no browser chrome; warm bone instrument-paper ground with a wide matte ink-black flight-recorder field occupying the upper two-thirds; very subtle technical grid and registration marks, not a generic SaaS dashboard.
Structure: compact top rail with wordmark EIGEN, tabs RUNS and COMPARE, small status text TEST MODE / OFFLINE VERIFIED; left vertical decision block reading PASS and ALLOW; the dominant center is one wide time-ordered strip chart with four clearly labeled horizontal lanes: MANDATE, AGENT, RAZORPAY, CLAIM. Six connected event stations travel left to right across the lanes: Authorised, Refund committed, Response lost, Razorpay checked, Same refund found, Truthful claim. Response lost is a crisp vermilion rupture; recovery is a cobalt bridge; success endpoint is green. Beneath the strip, a narrow evidence drawer shows selected event details, correlation ID, refund ID rfnd_test_001, amount INR 499.00, and one HTTP exchange row. Right edge has a compact proof checklist with exactly these labels: One refund authorised; One Razorpay test refund created; Response lost; Agent checks Razorpay state; No second refund created; Final claim matches Razorpay. Bottom edge hints at immutable run history as numbered recorder strips, not card tiles.
Style/medium: editorial instrument panel meets aviation flight-recorder chart and financial audit paper; disciplined Swiss typography; condensed display numerals plus highly legible sans serif labels; hairline rules, tabular numbers, physical print registration, restrained texture; no glossy 3D.
Composition/framing: desktop landscape, 1600x1000 feel, dense but calm, one dominant horizontal trace; large readable UI text; information-first.
Lighting/mood: flat studio daylight, serious, precise, forensic, confident.
Color palette: bone white #F2EEDF, ink black #101317, cobalt #2456FF, vermilion #E44A35, verification green #2E8B57; use color only for meaning.
